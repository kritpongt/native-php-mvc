# Project Mindset & Architecture

- **Long-Term Project**: This is a long-term project focused on long-term sustainability, maintainability, and clean architecture.
- **No Quick Fixes**: Do NOT implement quick fixes, temporary hacks, or brittle workarounds. Do not introduce technical debt. Hardcoding is strictly forbidden.
- **Quality over Speed**: Always prioritize code quality, robust architecture, and best practices over delivery speed. Solutions must be scalable, well-designed, and strictly follow the project's core MVC and security conventions.
- **Root Cause Resolution**: When fixing bugs, always investigate, identify, and resolve the underlying root cause of the issue rather than just patching the immediate symptoms.
